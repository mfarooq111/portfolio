# Muhammad Farooq Portfolio

React + Vite + MUI single-page portfolio. Dark theme by default with a light mode toggle.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Editing content

All text lives in `src/data/`. Edit those files, not the components.

| File | Controls |
|---|---|
| `profile.js` | Name, title, hero pitch, About text, quick facts |
| `services.js` | "What I Build" cards |
| `skills.js` | Skill groups |
| `experience.js` | Career timeline |
| `projects.js` | AI and deep learning projects (live links optional) |
| `research.js` | Publication |
| `approach.js` | "How I Work" principles |
| `reviews.js` | Client review + qualities |
| `credentials.js` | Education and certifications |

## Photo

Put your photo at `src/assets/images/me.png` (`.jpg`/`.webp` also work). If it's missing, the hero shows initials instead.

## Note

No email, phone, or social links are included, to stay within Upwork's policy.
